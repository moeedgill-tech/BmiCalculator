BMI Calculator
A clean, responsive web application to calculate and interpret Body Mass Index (BMI).

Features
Interactive UI: Users can input weight and height to get an immediate calculation.

Responsive Design: Styled with CSS to work seamlessly on both mobile and desktop browsers.

Dynamic Feedback: Provides visual feedback based on the user's BMI category (e.g., Underweight, Healthy, Overweight).

Technologies Used
HTML5: Structured the application content.

CSS3: Implemented responsive styling and layout.

JavaScript: Handled form validation and calculation logic.

Getting Started
Clone this repository: git clone [https://github.com/moeedgill-tech/BmiCalculator.git](https://github.com/moeedgill-tech/BmiCalculator.git)

Open index.html in your preferred web browser to view the application.
